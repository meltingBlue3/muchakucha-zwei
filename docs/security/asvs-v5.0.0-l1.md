## Audit contract

The focused audit rejects missing, duplicate, or unrecognized identifiers; altered official requirement text; non-L1 or non-applicable rows; absent test paths or named assertions; denylist/provenance drift; and a runtime denylist smaller than the policy-matching top 3000. The audit is offline: immutable upstream URLs and checksums are evidence, while committed assets are the execution inputs.

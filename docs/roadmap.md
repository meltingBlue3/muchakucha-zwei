# 产品路线图

只保留待办、待评估方向与待验收项；已实现的行为以代码和开发指南为准。

## 产品目标

让家人用很少的操作看清今天的安排、自己的分工，并记录共享信息。管理员维护属于低频操作，日常首页优先服务安排、任务和笔记。

## 待办

- **笔记置顶**：补齐持久化、API 和权限测试，再提供常用信息入口。
- **家庭首次使用引导**：自行创建家庭后引导邀请家人、添加第一条任务，可跳过；接受邀请后直接进入家庭今日页。
- **日文界面**：语言按设备选择，所有页面都已有中日两种文案。麦克风权限说明等迁移之外的任务列在 [i18n-migration.md](i18n-migration.md)，做法见 [客户端规程](agent/client.md#interface-text)。还要处理：
  - 固定宽度的标签列按两三个汉字设计，日文较长的词会折行；320px 宽度下页面标题「カレンダー」和底部标签「アシスタント」折成两行。
  - 日文文案由读日文的家人过一遍用词。

各项分别评估和验收，不捆绑推进。布局和表单的通用原则维护在 [design.md](design.md)，不再保存已完成的改造清单。

## 待验收

现有自动化与局部设备记录不能替代以下场景；重新验收时记录安装包版本、设备、权限和供电条件：

- **通用原生界面**：Android / iOS 大字体、软键盘避让、系统返回、日期选择、长内容与下拉刷新。
- **Android 通知与闹铃**：已有小米 Android 13 debug 包的局部实测。用新安装包确认日文界面的闹铃按钮、通知操作和闹铃频道，以及重启后首次响铃的语言。继续确认允许锁屏显示、后台弹出且关闭省电限制后的亮屏与页面展示；拔掉数据线、勿扰、划掉应用、重启、自启动限制下的行为；通知冷启动和「查看详情」；稍后再响到点后的触发，以及服务被系统停止后通知和按钮的清理。
- **iOS 本地提醒**：权限、到点展示、应用退出与设备重启后的排程、点击通知冷启动、容量边界。
- **农历与生日**：真机上月历农历小字在大字体和窄屏下的排版；「显示农历」开关在应用重启后保留；生日的「提醒我」在当天参考时间到点。
- **和历与日本祝日**：真机上月历里祝日的朱色数字和祝日名在大字体和窄屏下的排版，四个字的祝日名是否放得下；今天的浅朱底圆与祝日是否一眼分得开；「显示日本的祝日与和历」的选择在应用重启后保留。Android 和 iOS 的系统日期选择器不受这次改动影响。
- **界面语言**：需要装有 `expo-localization` 的新安装包。真机上确认系统为日文时首次打开即为日文、系统语言列表里日文排在英文之后也能选中、「语言」选择在应用重启后保留；应用内选的语言与系统不同时，日文汉字（直、骨、今）是否仍按系统语言的字形显示。
- **App 语音输入**：中文与日文的真实 M4A 转写、首次与永久拒绝权限、短录音、来电与后台切换，以及取消后资源释放。Web 的真实百炼转写记录不能代替这些检查。
- **真实对话模型**：本地网关的 `gpt-6.1-sol` 已通过中日文提问、指定英语回答、纯符号消息的界面语言回退，以及日文查询中文笔记和确认后创建笔记。继续用固定中文场景验证跨日程、任务和笔记查询、共享权限、冲突、批量部分失败，以及记农历生日、查节日和下次生日。记录最终数据正确性、错误写入、依据完整性与延迟。
- **家庭可用性**：观察查看安排、创建采购任务、找家人日程、共享笔记与邀请的成功率、耗时和误触。先建立真实基线，再定改善目标；少量家庭样本用于发现问题，不作为统计显著性结论。

## 待评估方向

- 提醒后台定期同步，只作为打开 App 同步的补充，需评估厂商系统限制。
- 助手模型能力标记、用量上限，以及查询过滤和分页下推数据库；按真实规模与失败样本决定优先级。
- 语音的人名词表或流式预览：分别评估额外数据发送与新接口成本。
- 宽屏的键盘与快速录入：桌面设计稿画过但还没实现的有三项。快捷键 N 在当前页创建，/ 聚焦页眉搜索，↑↓ 在清单里移动并让详情栏跟着切换；任务清单顶部有一行快速添加（「添加任务，回车保存」）；笔记编辑栏头显示「草稿已存在本机」。已实现的是 `Ctrl K` 和详情栏表单的 `Ctrl Enter`。
- 更多界面语言（如英文）：文案目录按语言分文件，新增一种语言是补一份目录；日期写法与复数规则届时再定。

## 非目标

不随视觉改造改变权限、日期和重复规则语义。当前不引入服务端推送、Web 通知、聊天、积分或位置跟踪。提醒采用本机排程，其能力与代价见 [开发指南](development.md#提醒与闹铃)。

# 前端设计重构

本文为历史实施记录。后续前端设计以 [前端设计规范](design.md) 为通用依据。

设计依据见 [Apple、Things 与 Cozi 官方资料调研](apple-inspired-design-research.md)。本轮在工作区原有体验改动之上实现，不改动服务端接口、身份验证或家庭权限规则。

## 设计体系

- 保留暖白 `#FFF8F2`、珊瑚红 `#B94736`、青绿 `#277A72`。
- 区分装饰分隔线 `separator` 与交互控件边界 `border`，浅化卡片时保留表单边界对比度。
- 32 主标题、24 页面标题、20 分组标题、16 正文；系统字体由平台适配层提供，不依赖未加载的 Noto 字体名称。
- 内容卡片使用 24 圆角、不透明白底；按钮与文本框保持独立的尺寸体系。
- 不加入持续动画或模糊特效，保留减少动态效果、高对比模式、字体缩放与安全区域处理。

## 页面与组件

| 范围 | 实现 |
| --- | --- |
| 导航 | 手机底部五入口；1024 及以上宽屏侧栏；家庭切换整合进顶栏，内容区使用有限最大宽度 |
| 今日 | 日期标题、三项真实数据概览与分组安排，加载时不显示虚假的零条数据 |
| 日历 | 白色月历面板，日期完整读屏名称和选中语义，区分今天与选中日，月份按钮明确图标 |
| 任务 | 标题优先的清单卡，状态操作和详情入口为独立按钮，保留取消、逾期、优先级与重复信息 |
| 笔记 | 统一标题与创建入口、青绿色图标容器、内容摘要及更新日期 |
| 家庭 | 统一页面层级、安静的管理卡片；账户和成员等共享面板继承新视觉体系 |
| 详情 | 白色阅读面板、统一间距及圆角，保留编辑入口 |
| 编辑 | 统一字体和输入框，任务、日程、笔记复用 FormActions，取消与提交层级一致，提交中保留文字并显示加载状态 |
| 登录与账户 | 品牌图标、系统字体、圆角面板和浅分隔线，与家庭内界面统一 |

共享实现集中在 `src/ui/`；字体平台差异集中在 `src/platform/typography/`。新增页面复用 PageIntro、TodaySummary 与 FormActions，不在路由内复制主题数值。

## 验证方式与边界

客户端 Jest 验证既有业务交互及独立任务操作、日历选择；全仓 TypeScript 检查接口兼容。UI Playwright 测试通过拦截 API 请求覆盖登录、家庭建立、草稿、错误恢复与页面切换，不连接或清空数据库。

设计检查使用 320、390、1440 三种视口，检查五个主页面的控件溢出、导航可达性和运行错误，并在手机视口运行 axe。截图中的家庭内容为测试夹具，生产页面仍展示实际 API 返回的数据。

原生 Android/iOS 真机视觉、系统级大字体与读屏操作需要设备验收；Web 自动化不能替代这部分验证。此次未修改 API 或数据库，未运行清库型集成测试。

## 本轮验证结果（2026-09-15）

- `pnpm --recursive typecheck`：通过。
- `pnpm --filter client test:quick`：29 组通过，329 项通过，2 项原有跳过。
- `pnpm --filter client exec expo export --platform all`：Android、iOS、Web 导出均通过。
- `UI_BASE_URL=http://127.0.0.1:8085` 下运行 `pnpm exec playwright test --config playwright.ui.config.ts`：15 项全部通过，15.7 秒。该地址为本地 `apps/client/dist` 静态服务，支持 SPA 路由回退。使用其他本地预览服务时可替换此变量；不设置时继续使用原有 Metro 服务。
- 五个主页面在 320、390、1440 视口均通过溢出、导航与运行错误检查；390 视口 axe 未发现严重或致命问题。
- `git diff --check`：通过。

开发服务验证曾因 Metro 整页加载超过测试时限而超时；最终以同一代码的 Web 导出产物完成全套 UI 检查，不以放宽断言或跳过失败用例代替验证。

## 后续界面精简

按反馈删除各主页面和登录区域的介绍性文案，保留操作说明和状态反馈。今日页移除“今天”大标题，日期字号与“今日事件”一致（20），恢复此前珊瑚色和中等字重；今日页不再显示三个创建入口。类型检查、329 项客户端测试和 15 项 Web 检查通过，并检查了 320、390、1440 视口。

## 账户入口与页面流程

### 未登录首屏

| Option | Description | Selected |
|--------|-------------|----------|
| 直接显示登录页 | 最快进入核心操作，页面底部提供创建账户 | ✓ |
| 品牌欢迎页 | 先展示产品价值，再选择登录或注册 | |
| 登录与注册并列选择页 | 两个入口同等突出，但会多一步 | |

**User's choice:** 直接显示登录页。

### 注册表单结构

| Option | Description | Selected |
|--------|-------------|----------|
| 单页精简表单 | 邮箱、昵称、密码一次完成，不重复输入密码 | ✓ |
| 两步注册 | 先填写邮箱与密码，再设置昵称 | |
| 逐步引导 | 每个页面只填写一个字段 | |

**User's choice:** 单页精简表单。

### 登录后去向

| Option | Description | Selected |
|--------|-------------|----------|
| 智能分流 | 有家庭组进入 Today，无家庭组进入家庭引导 | ✓ |
| 始终进入 Today | 无家庭组时在页面内展示空状态 | |
| 始终进入家庭组选择页 | 每次登录后主动选择 | |

**User's choice:** 智能分流。

### 启动会话恢复

| Option | Description | Selected |
|--------|-------------|----------|
| 保持品牌启动屏 | 判定完成后再显示正确页面，避免闪烁 | ✓ |
| 先显示登录页 | 恢复成功后跳转，但可能闪屏 | |
| 先进入主界面骨架 | 验证失败后再退回登录页 | |

**User's choice:** 保持品牌启动屏直到判定完成。

## 邮箱验证与密码恢复

### 注册后衔接

| Option | Description | Selected |
|--------|-------------|----------|
| 验证等待页 | 同设备链接自动继续，其他设备成功后引导登录 | ✓ |
| 返回登录页 | 验证完成后手动登录 | |
| 受限进入应用 | 未验证前只禁止家庭功能 | |

**User's choice:** 进入验证等待页。

### 验证链接异常

| Option | Description | Selected |
|--------|-------------|----------|
| 区分状态并给出下一步 | 过期重发、已使用登录、无效重新发起 | ✓ |
| 统一显示链接无效 | 实现简单但原因不清楚 | |
| 自动发送新邮件 | 步骤少但可能造成滥用 | |

**User's choice:** 明确区分结果并提供下一步。

### 重新发送反馈

| Option | Description | Selected |
|--------|-------------|----------|
| 成功提示与 60 秒倒计时 | 倒计时期间禁用按钮并保留打开邮箱引导 | ✓ |
| 只显示短暂提示 | 更简洁但容易重复点击 | |
| 按钮始终可点击 | 灵活但容易误操作和触发限流 | |

**User's choice:** 成功提示与 60 秒倒计时。

### 密码重置后

| Option | Description | Selected |
|--------|-------------|----------|
| 返回登录页 | 用新密码重新登录，边界清晰 | ✓ |
| 自动登录 | 步骤更少但重置同时承担授权 | |
| 留在成功页 | 用户主动点击前往登录 | |

**User's choice:** 显示成功确认并返回登录页。

## 会话与异常行为

### 多设备登录

| Option | Description | Selected |
|--------|-------------|----------|
| 允许多设备并存 | 每台设备独立 Token，退出只影响当前设备 | ✓ |
| 新设备挤出旧设备 | 规则简单但跨端不便 | |
| 一个移动端加一个 Web | 限制明确但规则更复杂 | |

**User's choice:** 允许多设备并存。

### 会话失效

| Option | Description | Selected |
|--------|-------------|----------|
| 解释原因并返回登录页 | 清理凭据，重新登录后尽量恢复目标路由 | ✓ |
| 静默返回登录页 | 简洁但用户不知道发生了什么 | |
| 持续重试刷新 | 可能造成循环请求 | |

**User's choice:** 清理会话、解释原因并返回登录页。

### 无网启动

| Option | Description | Selected |
|--------|-------------|----------|
| 保留会话并显示离线等待页 | 不误判退出，提供重试 | ✓ |
| 直接进入应用 | 请求失败时再提示 | |
| 返回登录页 | 容易把网络错误误判为凭据失效 | |

**User's choice:** 保留会话并显示离线等待页。

### 密码重置后的其他会话

| Option | Description | Selected |
|--------|-------------|----------|
| 撤销全部 Refresh Token | 所有设备用新密码重新登录 | ✓ |
| 只撤销当前设备 | 便利但安全性较弱 | |
| 保留全部会话 | 干扰最少但风险最大 | |

**User's choice:** 撤销该账户全部 Refresh Token。

## 视觉基调与认证页面

### 品牌气质

| Option | Description | Selected |
|--------|-------------|----------|
| 温暖、现代、克制 | 有家庭感但不幼稚，适合高频使用 | ✓ |
| 活泼、有趣、插画感 | 个性强但可能削弱信息效率 | |
| 极简、中性、工具感 | 清晰但家庭产品辨识度较弱 | |

**User's choice:** 温暖、现代、克制。

### 主色方向

| Option | Description | Selected |
|--------|-------------|----------|
| 暖珊瑚色与奶油白 | 深墨色正文，青绿色作为少量状态色 | ✓ |
| 鼠尾草绿与暖灰 | 平静自然但较通用 | |
| 靛蓝与浅灰白 | 可靠清晰但偏冷 | |

**User's choice:** 暖珊瑚色与奶油白。

### 认证页构成

| Option | Description | Selected |
|--------|-------------|----------|
| 字标、表单与抽象色块 | 保持辨识度并突出填写操作 | ✓ |
| 大幅家庭场景插画 | 情感强但小屏适配成本高 | |
| 纯表单 | 直接但缺少品牌辨识度 | |

**User's choice:** 品牌字标、简洁表单和抽象色块。

### 组件形态与密度

| Option | Description | Selected |
|--------|-------------|----------|
| 舒展触控与中等圆角 | 48–52px 控件，边框和轻微层次 | ✓ |
| 紧凑信息密度 | 同屏内容更多但不够移动优先 | |
| 大圆角卡片化 | 亲和但容易幼态并占空间 | |

**User's choice:** 舒展触控与中等圆角。

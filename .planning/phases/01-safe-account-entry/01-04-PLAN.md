<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Login credentials → API | Untrusted credentials attempt to create an authenticated session. |
| Native SecureStore/Web cookie → refresh API | Long-lived bearer material crosses platform-specific transport. |
| Refresh API → PostgreSQL | A device generation is atomically consumed, replaced, or revoked. |
| Browser Origin/CORS → cookie mutation | Ambient Web credentials could be triggered cross-site. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01 | Spoofing / Information Disclosure | login | high | mitigate | Argon2id, generic invalid response, verified-only session issuance, per-IP/account throttle tests. |
| T-02 | Spoofing / Denial of Service | refresh family | high | mitigate | Hash-only storage, atomic consume, successor chain, known-replay session revoke, two-device and concurrency tests. |
| T-03 | Spoofing / Tampering | Web cookie refresh | high | mitigate | Exact Origin, credentialed exact CORS, SameSite cookie, POST-only mutations, source-selected response mode, no JSON secret. |
| T-04-01 | Information Disclosure | client storage/logs | high | mitigate | SecureStore/native, HttpOnly/Web, memory-only access, structured redaction, storage assertions. |
| T-04-SC | Tampering | dependency supply chain | high | mitigate | No new installs; use the approved lockfile only. |
</threat_model>

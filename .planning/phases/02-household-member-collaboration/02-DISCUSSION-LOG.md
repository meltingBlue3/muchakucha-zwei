## 入口与切换

### 无家庭用户入口

| Option | Description | Selected |
|--------|-------------|----------|
| 并列双入口 | 同一页面提供“创建家庭”和“接受邀请”，不预设意图 | ✓ |
| 创建为主 | 突出创建家庭，邀请作为次要入口 | |
| 邀请自动优先 | 有待处理邀请时优先邀请，否则主推创建 | |

**User's choice:** 并列双入口。
**Notes:** 直接替换 Phase 1 的家庭占位页。

### 多家庭切换入口

| Option | Description | Selected |
|--------|-------------|----------|
| 顶部家庭选择器 | 顶部持续显示当前家庭，点击打开家庭列表 | ✓ |
| 侧边栏或抽屉 | 与主导航一起呈现家庭切换 | |
| 个人页内切换 | 从资料或设置页管理当前家庭 | |

**User's choice:** 顶部家庭选择器。
**Notes:** 当前家庭需要在日常家庭页面保持可见。

### 默认家庭恢复

| Option | Description | Selected |
|--------|-------------|----------|
| 记住本设备上次选择 | 每台设备独立恢复；资格失效时回到家庭选择 | ✓ |
| 跨设备同步最后选择 | 所有设备共享账户的最后选择 | |
| 每次都让用户选择 | 登录后总是先进入家庭列表 | |

**User's choice:** 记住本设备上次选择。
**Notes:** 一台设备的切换不能影响其他设备。

### 写入上下文提示

| Option | Description | Selected |
|--------|-------------|----------|
| 持续显示 + 表单标注 | 顶部显示家庭，表单再标注保存目标 | ✓ |
| 提交前每次确认 | 每次保存前弹窗确认家庭 | |
| 仅危险操作确认 | 普通操作只依靠顶部名称 | |

**User's choice:** 持续显示 + 表单标注。
**Notes:** 普通保存不增加弹窗。

## 邀请闭环

### 邀请时的初始角色

| Option | Description | Selected |
|--------|-------------|----------|
| 统一以 member 加入 | 加入后再显式提升权限 | ✓ |
| 可选 member 或 admin | 邀请时直接指定角色 | |
| 仅 owner 可邀请 admin | owner 和 admin 的邀请能力不同 | |

**User's choice:** 统一以 `member` 加入。
**Notes:** 邀请表单只要求邮箱。

### 账户状态隐私

| Option | Description | Selected |
|--------|-------------|----------|
| 不透露账户状态 | 统一显示邀请已发送；已是本家庭成员可明确提示 | ✓ |
| 显示已注册或未注册 | 向邀请人展示平台账户状态 | |
| 完全统一反馈 | 已是家庭成员也不明确提示 | |

**User's choice:** 不透露账户状态。
**Notes:** 兼顾账户隐私和邀请人已获授权的家庭成员信息。

### 邀请与认证衔接

| Option | Description | Selected |
|--------|-------------|----------|
| 先预览，再认证并明确接受 | 展示家庭和邀请人；认证后由用户点击接受 | ✓ |
| 认证后自动接受 | 登录或注册后直接加入 | |
| 先认证，再显示邀请内容 | 未认证时不展示邀请预览 | |

**User's choice:** 先预览，再认证并明确接受。
**Notes:** 接受邀请不能作为认证的隐式副作用。

### 受邀身份绑定

| Option | Description | Selected |
|--------|-------------|----------|
| 必须匹配受邀邮箱 | 不匹配时引导切换账户 | ✓ |
| 持链接者均可接受 | 任何登录用户可凭链接加入 | |
| 接受时改绑账户 | 将邀请转给当前登录账户 | |

**User's choice:** 必须匹配受邀邮箱。
**Notes:** 账户不匹配时不得继续泄露邀请细节。

## 成员治理

### admin 权限范围

| Option | Description | Selected |
|--------|-------------|----------|
| 管理所有非 owner 成员 | 可管理普通成员和其他 admin | ✓ |
| 只管理普通 member | 其他 admin 仅由 owner 管理 | |
| 接近 owner | 除所有权转移外具备全部管理能力 | |

**User's choice:** 管理所有非 owner 成员。
**Notes:** admin 不能处理 owner 或转移所有权。

### 危险操作确认

| Option | Description | Selected |
|--------|-------------|----------|
| 分级确认 | 降级和移除使用确认页；所有权转移增加最终确认 | ✓ |
| 统一单次确认 | 所有危险操作只确认一次 | |
| 全部强确认 | 每次都要求输入家庭名称 | |

**User's choice:** 分级确认。
**Notes:** 确认内容必须明确成员、家庭和后果。

### owner 离开家庭

| Option | Description | Selected |
|--------|-------------|----------|
| 选择继任者后原子完成 | 转移所有权并移除原 owner | ✓ |
| 先转移再退出 | 拆分为两个独立操作 | |
| owner 不允许离开 | owner 永远保留成员关系 | |

**User's choice:** 选择继任者后原子完成。
**Notes:** 两个记录变化必须整体成功或整体失败。

### 当前家庭权限丢失

| Option | Description | Selected |
|--------|-------------|----------|
| 明确告知并重新选择 | 停止当前操作，说明变化并进入家庭选择 | ✓ |
| 自动切换到另一个家庭 | 不提示地改变当前家庭 | |
| 返回登录页 | 将授权变化表现为会话失效 | |

**User's choice:** 明确告知并重新选择。
**Notes:** 无其他家庭时返回创建/接受邀请双入口。
